'👌👌👌❤️❤️❤️Parent Pattern: DFS with State Carrying

Template:

def dfs(node, state):
    if node is None:
        return

    state = update(state, node)

    if is_goal(node):
        return answer_from(state)

    dfs(node.left, state)
    dfs(node.right, state)
